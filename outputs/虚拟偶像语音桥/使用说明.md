# 虚拟偶像语音桥

本工具把 Qwen3-TTS 生成并实际播放的 24 kHz PCM 语音转换成 A/I/U/E/O 五元音口型，通过 Mocap 动作总线的 `voice` 来源发送给 Blender。

当前连接：

- TTS：`http://127.0.0.1:8091/v1/audio/speech`
- 口型来源：UDP `127.0.0.1:39543`
- 沃雅妮莎嘴部：订阅 `voice / mouth`
- 语音停止或来源异常：约 40 ms 过渡到闭嘴 `rest`

双击 `测试实时口型.cmd` 可以现场生成、播放并驱动一次测试语音。Qwen3-TTS 流式服务需要先运行。

命令行示例：

```powershell
.venv\Scripts\python.exe voice_avatar_bridge.py `
  --text "你好，这是实时口型测试。" `
  --output-wav test.wav `
  --plan test.json
```

也可以使用现成 WAV：

```powershell
.venv\Scripts\python.exe voice_avatar_bridge.py `
  --text "与音频完全相同的台词" `
  --wav speech.wav
```

`--latency-offset-ms` 用于设备校准：正值让嘴型稍微提前，负值让嘴型稍微延后。默认 0，播放时使用 PortAudio 的 DAC 时钟校正，不按“命令发出时间”猜测。

## 当前验证

- 6.32 秒现场语音：TTS 1.387 秒，口型规划 0.014 秒。
- 190 个口型帧，其中 153 帧有效张嘴。
- 总线收到 A/I/U/E/O 五通道，沃雅妮莎订阅端发送错误为 0。
- 播放结束后嘴部回到 `rest`。

口型由已知台词的拼音韵母、实际 PCM 能量和音频静音谷联合生成。它比仅按音量开合更具体，并且不会额外占用大型语音识别模型显存。最终观感仍可针对角色嘴型幅度与具体音频设备延迟继续校准。
