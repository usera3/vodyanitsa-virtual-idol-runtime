# Mocap 屏幕桥 · 窗口捕获版

从指定应用窗口直接捕获画面，实时送入 AGI Mocap。窗口被其他软件遮住、移动、缩放或改标题后，仍跟随同一个窗口；也保留原来的屏幕区域模式。

## 使用

1. 双击 **Mocap屏幕桥.exe**。请保留旁边的 `_internal` 文件夹。
2. 点击 **选择应用窗口**，从正在运行的应用列表选择具体窗口。可搜索应用名或窗口标题，也可刷新列表。
3. 检查预览；如果只要人物所在区域，点击 **裁剪窗口画面**，在窗口截图里拖选矩形。点击 **开始推送**。
4. 在 AGI Mocap 的摄像头下拉框里选择 **OBS Virtual Camera**。必要时重新选择该摄像头。
5. 按原来的方式使用 Mocap 与 miko Blender 的实时联动。

软件只负责输入画面，不改变 Mocap 的识别算法或 Blender 绑定。

## 控件说明

- **仅预览**：检查框选画面，不占用虚拟摄像头。
- **选择应用窗口**：使用 Windows Graphics Capture 直接捕获指定窗口，不截取它后方或上方其他程序的画面。
- **裁剪窗口画面**：在未镜像、未裁剪的完整窗口图像上选择范围；按 Esc 取消。裁剪位置按窗口比例保存，窗口缩放时跟随调整。
- **恢复完整窗口**：清除裁剪范围。选择来源或修改裁剪会先停止当前推送，重新进入预览，之后再点击开始推送。
- **屏幕区域**：兼容旧模式，在桌面上拖选区域；这种模式仍会受遮挡影响。
- **开始推送**：把画面送入本机 OBS Virtual Camera。
- **停止采集 / 推送**：停止截屏、清空预览并释放虚拟摄像头。窗口获得焦点时按 Esc 也可以停止。
- 修改分辨率、帧率或镜像前，先停止。
- 支持横屏/竖屏 720p 和 1080p，15/30/60 目标帧率。实际速度显示在预览下方，受电脑负载影响。
- 原始比例保持不变，空余部分填黑，不把人物拉宽或拉长。

## 注意

- 当前电脑已有 OBS 虚拟摄像头驱动，不需要启动 OBS 软件。**不要同时启动 OBS 的虚拟摄像头输出**，因为这个通道只有一个输出实例。
- 当前 AGI 版本存在长运行内存增长。2026-09-24 的实测中，AGI 保持打开而屏幕桥停止推流时，AGI 内存增长反而明显加快；恢复推流也没有清除已积累的状态。长时间使用建议先开始屏幕桥推流再打开 AGI；结束时先退出 AGI，再停止屏幕桥。详见工作区 `outputs/AGI_Mocap长运行卡顿调查.md`。
- **应用窗口模式允许遮挡**。目标窗口最小化或隐藏时输出黑帧并显示等待状态，恢复窗口后自动继续。目标窗口关闭后停止采集，不会偷偷切到桌面。
- 最小化不等于遮挡。Windows 和应用可能暂停最小化窗口的渲染；部分浏览器、播放器、游戏也可能自行暂停后台内容，因此不要依赖最小化后的画面更新。受保护视频或不支持捕获的窗口可能黑屏。
- **屏幕区域模式**仍然不能被遮挡，也不要把本工具、Mocap 或 Blender 窗口放进选区，否则遮挡或画面递归也会被捕捉。
- 选择清晰、完整的人体画面，尽量包含头和脚。网页/播放器弹幕、字幕、切镜头和遮挡会影响识别。加大推流分辨率不会补回原视频没有的细节。
- 软件不会自动录制或上传屏幕，也不会在下次打开时自动开始采集。只保存分辨率、帧率和镜像偏好。
- 偏好与错误日志：`%LOCALAPPDATA%\MocapScreenBridge`。日志不包含截屏内容。
- 此便携包适用于 Windows x64。换电脑需要先安装 OBS Studio 的虚拟摄像头驱动。

## 本机验证范围

已验证真实窗口被完整遮挡时，桌面读取的确是遮挡层，而 Windows Graphics Capture 仍得到目标窗口持续变化的画面；经同一个推送工作线程发送到 OBS Virtual Camera 后，FFmpeg DirectShow 连续接收到 45 帧、三种变化色块，约 30 fps。

还验证了窗口移动、缩放、改标题、最小化/恢复、开始时已最小化、关闭目标自动停止，以及从列表选择窗口、裁剪、恢复完整窗口、预览/停止/关闭。旧屏幕模式的负坐标和反向框选、等比填充、镜像、虚拟摄像头停止后重新占用等检查仍保留。

没有自动操作 Mocap 的摄像头下拉框完成最终识别验证：本次 Windows 窗口控制接口不可用。请按上面的第 4 步选择摄像头，看 Mocap 输入画面是否和预览一致。

## 源码与构建

`source` 包含完整 Python 源码、依赖版本与测试。界面基于 Tkinter；窗口模式使用 windows-capture / Windows Graphics Capture，按 HWND 与 PID 锁定目标；屏幕模式使用 MSS；虚拟摄像头使用 pyvirtualcam。运行时无需 Python，打包使用 PyInstaller。

在 Python 3.12 x64 的独立环境安装依赖后：

```powershell
python -m pip install -r source/requirements.txt
python source/screen_bridge.py
python source/test_bridge.py
python -m PyInstaller --noconfirm --onedir --windowed --name MocapScreenBridge --collect-all pyvirtualcam --collect-all windows_capture source/screen_bridge.py
```
