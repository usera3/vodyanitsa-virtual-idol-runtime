## 还没稳住的

1. **小度自己的唤醒音**。一开口先听到短的 “我在 / I'm here”，那是音箱固件，不是千问。小度 App 里关掉语音助手唤醒，只当蓝牙音箱+麦。
2. **Spark 爱用英文问候**。真正的角色回复经常是 `Hey. I'm here...`。过滤之后千问会静音；用户会以为预设还在。要中文对白，得改 Yuri 的 Spark 提示词，让她用中文说话。
3. **听觉误触发**。小度 RMS 很低，Whisper 常听成「嗨 / 有 / 嗯」，再去打聊天。捂耳朵已经加上，阈值还可以再收。
4. **YuriOS 面板 `/ws/voice`**。浏览器开着圣地/语音页时，会走 YuriOS 自己的 filler/问候 PCM。健康接口里 voice 是 `unloaded` 才安全。演示时不要开 YuriOS 麦。
5. **Windows → WSL 8768 NAT 是坏的**。聊天和 SSE 用 `wsl curl`。本地回环必须绕过 `HTTP_PROXY`。
6. **裙子物理 vs 跳跃**。根位移已经回滚。离地需要单独的根控制和裙摆重置，不要把旧 Hips 补丁加回去。
7. **Grok 后台进程活不过会话**。交接后若会话关掉，YuriOS / TTS / 心智桥 / 听觉都要按 cmd 入口重拉。
