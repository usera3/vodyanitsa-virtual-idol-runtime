# 生命层：让身体一直醒着

写于 2026-09-26。这是给沃雅妮莎（以及同一条身体总线的薇斯纳）用的控制架构，不是新的动作生成器。

前提已经成立：动作总线能按部位叠源，ARDY 能生成任意技能，语音桥能对口型，拟人层能 30 Hz 推 22 骨，YuriOS 能想和记。缺的是一个一直在跑、并且知道“她现在是谁、在注意什么”的身体导演。

## 一句话

活人站着，是一个带社交设定点的闭环稳定器。呼吸、眨眼、换重心、移开视线，都是体内不平衡在被纠正。挥手、鞠躬、跳舞是短暂扰动。扰动结束，稳定器还在，人就还在。

动作生成解决“她能做”。生命层解决“她为什么现在动、动完为什么还像同一个人”。

## 现在为什么还不像醒着

当前链路是事件驱动的管道，不是一个人。

| 现成的 | 实际在干什么 | 缺口 |
|---|---|---|
| `embodiment_controller.py` | 30 Hz 振荡器 + 随机 fidget + 关键词舞台提示 | 不知道她在听、在想、还是刚说完 |
| `mind_action_bridge.py` | 用户消息 → 听；`audio_ready` → 说；舞台 `*...*` → 头/表情 | 规划那几秒没有“想” |
| `pose_snapshots` | 用相对单位四元数的转角判断面向/垂手 | 待机本身就不是单位姿态，判断会漂 |
| 动作总线 | 技能按 mask 播放，结束后 rest | 生命层不知道技能抢走了哪些骨 |
| 语音桥 | 每个字有 start/end，口型跟 DAC 时钟 | 身体拿不到这些拍子 |
| YuriOS | `SENSE→APPRAISE→DECIDE→ACT`，事件请求是 `presence=0&body=0` | 心智几乎不碰身体 |
| ARDY / Laya | 会做事、会记住做过的事 | 被拿来填待机就会暴露生成器 |

随机 fidget 看起来像活，是因为有时碰巧像。它没有交际功能：不会在你开口时安静下来，不会在她思考时把眼睛拿开，不会在说完后回到“看着你、还在呼吸”。人能一眼看穿。

学术上这是 SAIBA 的第三段没接上：意图（YuriOS/Agnes）和实现（Blender/VMC）中间，缺行为调度。不必上 BML XML。要的是一个小的、一直在跑的身体导演。

Convai 的拆法和我们要对齐：呼吸永不关；脚本动作来了，生命层让出被占用的部位，而不是整身关机；听、说、闲是同一套求解器换设定点，不是切另一段动画。

## 三个时钟，不准混

```
心智时钟（稀疏，可慢）     身体导演（10 Hz 决策）     实现时钟（30 Hz）
YuriOS / Agnes / Laya  →  模式、注意、技能请求   →  embodiment + 总线 + 口型
想什么、说什么、记什么       现在该看谁、该不该静      每帧骨骼和 morph
```

大模型不准进 30 Hz。APPRAISE 本来就不该每拍打模型。身体导演自己根据事件和体内驱动做决定。

心智允许输出的，只有这类东西：

```text
mode:        rest | listen | think | speak | act
look_at:     user | away | down | hold
energy:      0..1
mood:        calm | warm | shy | alert
skill?:      {id or ardy, mask, seconds}
speech?:     {audio_seconds, unit_starts[]}
```

心智不准输出逐帧骨骼，不准把“挥手”写成无限循环，不准在心跳里为了找事做而调用 ARDY。

## 她是一个稳定器

给身体几条会慢慢涨、涨到阈值就释放的驱动。释放就是一次短运动程序（0.3–2.5 秒），不是 ARDY。

| 驱动 | 何时上涨 | 释放时做什么 | 谁能按住它 |
|---|---|---|---|
| 呼吸 | 节律，不靠阈值 | 胸腹肩头错开的波浪 | 无人按住，技能来了也留着 |
| 眨眼 | 2.4–6.2 秒 | 一次或连眨 | 只有明确的眨眼表演 |
| 平衡 | 单脚承重过久 | 换重心 | 全身技能 |
| 注视疲劳 | 锁定同一目标过久 | 扫视或移开再回来 | 听的时候阈值提高（更盯得住） |
| 手静止 | 手腕太久没动 | 轻微腕/肩 | 手臂被技能占用，或正在听 |
| 社交注视 | 人在、却没在看人 | 眼头回到用户 | think 允许暂时移开 |
| 不安 | 长时间没互动 | 环视、理裙、换脚 | listen / speak / act |
| 回正 | 技能刚结束 | 平滑回到角色待机基准 | 新技能立刻开始 |
| 开口气 | 即将说话 | 说前 0.2–0.4 秒吸气 | 无 |

闲着时她会动，是因为有一条驱动满了。听你说话时安静，是因为听把大部分驱动的阈值抬高。这就是生命，不是播放列表。

还要一条很慢的宏观漂移（90–180 秒）：呼吸深度、换重心周期、扫视间隔轻轻走形，避免 6.4 秒循环被看出来。Convai 把这叫做 idle macro-cycle。

## 注意是主通道

眼神比手臂更能让人觉得对面有意识。看向目标时，眼睛先到，头跟上，胸再跟上一点。这是 SmartBody 注视控制器的顺序：眼快、头慢、躯干更慢。目标切换不要三块骨头同一帧转到位。

| 模式 | 眼睛 | 身体 | 驱动政策 |
|---|---|---|---|
| rest | 大部分时间看用户，偶尔拿开 | 完整生命层 | 正常释放 |
| listen | 锁用户，极少拿开 | 略前倾，幅度变小 | 手/环视按住，眨眼和呼吸留下 |
| think | 移开 0.4–0.8 秒，可向上或向侧，再回来 | 更静 | 允许注视疲劳立刻释放一次 |
| speak | 约七成看用户，从句边界可拿开 | 开口前吸气；重音处头或手轻轻一送 | 手可跟拍，环视按住 |
| act | 技能 mask 内交给 ARDY | 生命层只留呼吸眨眼；mask 外继续 | 技能占用的驱动按住 |
| settle | 看回用户 | 0.5–0.8 秒把被抢的骨交还待机基准 | 回正驱动工作 |

一轮对话的身体时间线，比任何动作库都重要：

```
用户开口/消息到达     → listen   安静看着你
开始规划（Laya/Agnes） → think    眼睛拿开，像在想
audio_ready 前 0.3s   → 吸气
播放语音              → speak    口型由语音桥；头/手跟字的拍子
播放结束              → settle   手放下，看你
之后                  → rest     稳定器继续
```

今天规划那几秒她还停在 listen。那是最假的一段：人在想的时候会把视线拿开。机器人会继续死盯。

规划若在 0.2 秒内就结束（Laya 判定无动作、本地模板立刻 `audio_ready`），不要硬做完一次移开眼睛。开始移开、话已经到了，就看回来——人也是这样。只有规划明显超过约 0.4 秒时，才允许完整的 0.4–0.8 秒移开。

语音桥已经给每个字标了 `start/end`，并且口型跟 DAC。身体导演只要一份稀疏拍子：能量谷、字边界、句边界。不要每个 viseme 都做手势。McNeill 的分类里，日常说话主要是 beat（节拍），不是 icon（比划物体）。没有道具的空舞台上，beat 就够了。

## 叠层与让路

和动作总线现有 mask 对齐，不要再做一套骨骼战争。

优先级从低到高，同骨只留一个主写手，生命层的呼吸作为加性例外：

1. 生命：呼吸、眨眼、平衡、宏观漂移
2. 注意：眼、头、听时前倾
3. 手活着：腕、肩微动
4. 说话节拍：头点、很小的手
5. 技能：ARDY / 标签动作，按 `full | upper | arms`

让路规则（直接抄 Convai 已经验过的表）：

- 没有技能：全开
- 上半身或手臂技能：头的节拍可留，姿势脉冲减小，语义手势拒绝，呼吸全开
- 全身技能：节拍和姿势让出，呼吸仍全开
- 技能结束：mask 里的骨必须释放，回正驱动接手。禁止停在最后一帧

沃雅妮莎的手臂有已验收锥：上臂世界方向大约 `(±0.20, 0, -0.98)`。生命层和回正在这个锥里工作。技能可以离开，结束后必须回到锥里。髋部只旋转，不平移。

## 角色状态（身体的真相）

存在身体导演里，每帧更新，技能和舞台提示都必须先读再动。

```text
mode, look_at, energy, mood
weight_foot: left | right | even
gaze_yaw, gaze_pitch, gaze_target
seconds_in_mode
seconds_since_user
seconds_since_skill
arm_directions          # 来自 Blender 实时连接状态，不是单位四元数转角
head_to_camera_deg      # 面向用户的真值
skill_mask, skill_until
speech_remaining
drives{...}
```

`facing_user` 不要再用相对单位姿态的转角。待机本身就有髋偏和 12° 垂臂，那个角会撒谎。面向应以 Blender 里头/胸朝向与摄像机的夹角为准，写进 `实时连接状态.json`，导演去读。

舞台提示继续可以用。规则只有一条：提示是相对当前状态的补丁。已经在看你，就不要再“转身望向你”。手已经在锥里，就不要再“放下双手”当成大动作。

## 现有事件已经够接时间线

不必等 YuriOS 开放 body 通道。桥里这些回调已经在发生：

| 已有钩子 | 今天做了什么 | 生命层应改成 |
|---|---|---|
| SSE `role=user` | `set_listening()`，停技能，停语音 | `mode=listen`，抬高注视阈值，按住环视 |
| `_submit_semantic_plan` / `_plan_and_execute` 开始 | 无 | `mode=think`，释放一次注视疲劳（眼睛拿开） |
| `SpeechWorker.state_callback(True)` | `set_speaking(True)` | 若尚未吸气则补吸气，`mode=speak` |
| `_on_speech_ready` | 开始舞台 cue | 附带字边界，生成 1–4 个 head beat，禁止再“转身看你”如果已在看 |
| `SpeechWorker.state_callback(False)` | `set_speaking(False)` | `mode=settle` 0.6 秒，再 `rest` |
| `hub.dispatch` / `set_action` | 拟人层降到 20% | `mode=act` + mask，mask 内停写 |
| `_recover_pose_after_action` | 请求 rest | 回正驱动，回到垂臂锥 |
| 用户插话 | 已打断语音和动作 | 立刻 listen，清 speak/act，驱动不要在打断后爆 |

第一档升级几乎全是改这些钩子的设定点。新动画可以一个都没有。

身体导演和 30 Hz 实现放在同一进程、同一线程最稳：每帧先 tick 导演（更新驱动和模式），再 sample 骨骼。不要再开一个 10 Hz 进程去抢 UDP。

## 插在现有文件的哪里

不新开进程。身体导演是拟人层的脑子，实现层还是 30 Hz UDP 39544。

| 模块 | 职责 |
|---|---|
| 新：`life_director.py` | 状态、驱动、模式、注意目标、短运动程序调度 |
| 改：`embodiment_controller.py` | 只负责把导演的目标变成 22 骨 + morph；去掉无原因的随机 fidget |
| 改：`mind_action_bridge.py` | 用户消息 → listen；规划开始 → think；`audio_ready` → speak+拍子；技能 dispatch → act；结束 → settle |
| 改：语音桥 `audio_ready` | 附带 `units[].start/end` 或能量谷时间，供说话节拍 |
| 改：沃雅妮莎启动器 | 上报 `head_to_camera_deg`、`arm_directions`（已有） |
| 后：YuriOS 适配器 | 只改设定点（mood/energy/look_at），仍不写骨骼 |
| 后：Laya | 只映射反复出现的技能，不映射生命 |

拟人状态文件加上导演可见字段：`mode`、`look_at`、`drives`、`skill_mask`。调试靠这个，不靠猜。

## 心智以后怎么用身体

YuriOS 的 ENGAGED / IDLE 正好对应社交设定点。心跳可以做的事：

- 把 mood、energy、look_at 缓缓改掉
- 很久没人理，把不安驱动的上限放开（她会自己环视）
- 真的要主动说话时，先切 think，再走现有语音门
- 不要为了“做点什么”调用 ARDY

Laya / ARDY 的位置不变：用户明确要做事，或心智决定做一个有名字的技能。生命层不排队去生成新的待机。

## 必须防住的死法

1. 驱动一起爆：技能结束后所有驱动都是满的，会连续抽搐。回正期间把其它驱动清掉或加长阈值。
2. 听的时候还在表演：listen 必须按住环视和大幅度换重心。
3. 想的时候还在死盯：规划一开始就要 think，不能等第一句语音。
4. 技能和生命抢手臂：只认总线 mask，导演在 act 期间不写 mask 内的骨。
5. 面向判断撒谎：改摄像机夹角。
6. 口型手势一对一：每个 viseme 都动手会像口技木偶。只在能量峰和句边界给 beat。
7. 髋平移：继续禁止。平衡只用旋转。
8. 衣裙物理长时间崩溃：生命包含“还能穿那条裙子”。导演每隔几分钟可请求一次已有的 `blend_to_rest` / 物理轻重置，这是保命，不是表演。
9. 大模型进心跳：设定点可以几秒变一次；骨骼只有导演和实现层写。
10. 用 ARDY 填安静：安静必须是稳定器，生成器会在第三十秒露出马脚。

## 怎么验收她醒着

不看动作库条数。看这一轮：

1. 打开窗口，没人说话，她已经在呼吸、换重心、偶尔眨眼和瞟。
2. 你一发消息，她明显安静下来看着你。
3. 等待回复的那几秒，她把眼睛拿开再看回来。
4. 她开口前胸口有一个小吸气；说话时头跟节奏，不是整段舞。
5. 说完手不僵在半空，一两拍内回到垂臂锥，还在看你。
6. 跳完或挥完，她还是同一个人站着，不是 A-pose，也不是技能首帧。
7. 十分钟后裙子还在，眨眼还在，没有内存把窗口拖死。

以上七条过了，生命层才算立住。然后再谈主动搭话、道具、蒸馏。

## 升级顺序

每一档单独可看、可回退。

1. **对话身体时间线**：listen / think / speak / settle 接到桥上已有事件。这一档不新生成任何动作，只改现有拟人层的设定点。收益最大。
2. **驱动替换随机 fidget**：平衡、注视疲劳、手静止、社交注视。随机抽签退休。
3. **真值姿态**：摄像机夹角 + 已有 `arm_directions` 写入导演状态。舞台提示和回正都读它。
4. **说话节拍**：`audio_ready` 带上字边界；开口吸气 + 少量 head beat。口型仍只由语音桥写。
5. **技能让路协议**：act 期间导演尊重 mask；结束强制回正到垂臂锥。
6. **宏观漂移 + 物理保命**：慢变周期；定时轻量 rest。
7. **YuriOS 设定点**：mood / energy / 主动看一眼。工具和 ARDY 仍关在心跳外。
8. **Laya 只记技能**：打招呼、挥手、鞠躬。生命层不进肌肉记忆。

## 明确先不做

- 不把 ARDY 当待机发生器
- 不上桌椅门窗
- 不写手指追踪
- 不在 30 Hz 里调用任何语言模型
- 不把 YuriOS 网页 VRM 接回来
- 不把生命层做成可播放的 clip 文件

## 关键决定

1. 生命是闭环稳定器，技能是扰动。选定它，是因为人站着本来就是平衡系统，不是动画状态机。
2. 三个时钟分开。选定它，是因为现有卡顿都来自用慢模型去填快身体。
3. 注意（眼/头）优先于手。选定它，是因为对话角色 90% 的时间在看和听，不是在比划。
4. 呼吸和眨眼在全身技能下也留下。选定它，是因为停呼吸等于死。
5. 规划阶段必须进入 think。选定它，是因为现在最假的就是“计算时还在对你微笑死盯”。
6. 姿态真值来自 Blender 摄像机，不来自单位四元数。选定它，是因为已验收待机本来就不是单位姿态。

## 回到目标

目标不是更聪明的动作菜单。目标是打开窗口她就在。你去吃饭的时候她也该自己站着、呼吸、换脚、偶尔看一眼镜头——因为不安和平衡在涨，不是因为随机数抽中了“环视”。

等七条验收过了，这具身体才配接上心智，说那句：以后这是你的身体。
