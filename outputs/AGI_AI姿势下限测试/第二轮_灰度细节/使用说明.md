# 第二轮：灰度画面的细节下限

用户已观察到：AI 彩色人形和灰度人形能被 AGI 跟随；纯黑剪影可识别身体，但正反面不稳定；火柴人及更稀疏画面未观察到可靠跟随。这一轮只从已有效的 AI 灰度姿势图出发，分别降低空间细节或灰阶数，不再改变人体外形。

在 AGI “打开视频”中选择 `C:\Users\mozi\Videos\AGI_TEST_09_GRAY_LIMIT.mp4`。同一文件也保存在此目录，长 63 秒，720×720 H.264、30 fps。视频中三个静止姿势 A、B、C 各保持 3 秒，连续组成每档 9 秒。

| 时间 | 画面处理 |
|---|---|
| 0–9 秒 | 原灰度图，对照 |
| 9–18 秒 | 降到 384×384 细节后放回 720×720 |
| 18–27 秒 | 降到 256×256 细节后放回 720×720 |
| 27–36 秒 | 降到 160×160 细节后放回 720×720 |
| 36–45 秒 | 保留 16 级灰度 |
| 45–54 秒 | 保留 8 级灰度 |
| 54–63 秒 | 保留 4 级灰度 |

每档单独的 MP4 也在这里，便于从头打开检查是否能独立识别。所有文件编码分辨率保持 720×720，以隔离“画面细节”这一变量；这轮还不能证明 AGI 接受相同大小的原生低分辨率视频。`合成验证.json` 记录顺序、时长、帧数和 SHA256，`灰度细节姿势对照.png` 供快速核对画面。真实结果以用户在 AGI 的观察为准。
