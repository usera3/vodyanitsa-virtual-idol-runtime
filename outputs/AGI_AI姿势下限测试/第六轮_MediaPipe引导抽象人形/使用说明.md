# MediaPipe 引导的抽象人形测试

本轮依据 [Google BlazePose 检测与跟踪流程](https://research.google/blog/on-device-real-time-body-pose-tracking-with-mediapipe-blazepose/) 的公开说明设计：先由脸定位人体区域，再跟踪关节；头应可见，人体中心、肩髋方向和整体范围也参与定位。公开[模型卡](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf)提醒要把完整单人置于画面中并留适当边距。AGI 安装包有 MediaPipe 组件，但不能据此断定它使用相同版本或阈值。

源图仍是本项目先前 AI 直接绘制的 A（T字）、B（举臂）、C（下蹲）三张姿势；没有用真人视频帧。六档只修改正面线索、人体体积感或边距：

1. 真实五官＋黑色人形
2. 真实五官＋整体柔和明暗
3. 点画五官＋整体柔和明暗
4. 低纹理灰身＋真实脸
5. 真实五官＋圆柱四肢
6. 真实五官＋黑色人形缩小，增加四周边距

`00_MediaPipe引导抽象人形总览.png` 并排展示所有姿势。双击 `gallery.html` 后左侧选风格、A/B/C 姿势；按 ← / → 换风格，1 / 2 / 3 换姿势。可先点“白屏重置”，再选择下一种风格，减少上一帧跟踪状态对“从零检测”的干扰。用 Mocap 屏幕桥捕获此浏览器窗口的**右侧图像**，在 AGI 中选 OBS Virtual Camera。单独的每档 9 秒 MP4 和合并的 `00_抽象人形对照_54秒.mp4` 也可直接作为 AGI 视频输入。

本机公开版 MediaPipe Pose Landmarker Lite 在单帧模式下对六档的 A/B/C 图均返回姿态，但这只是**预筛选**。用户随后实测 AGI：只有 03“点画五官＋整体柔和明暗”完全识别失败，其余五档能识别。因此公开模型的检测结果不能代替 AGI 实测。第七轮在固定的 03 身体上只替换少量面部信息，以确定哪些真实五官细节足够。`合成验证.json` 记录视频顺序、帧数、素材哈希与公开模型预筛选结果。
